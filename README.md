# JavaScript DSA Assignment

## About
This repository contains solutions to 10 foundation-level JavaScript Data Structures and Algorithms problems.

## Questions Solved
1. Find the Second-Highest Score
2. Remove Duplicate Product IDs
3. Count Character Frequency
4. Reverse a String
5. Find the Missing Roll Number
6. Check Whether Text Is a Palindrome
7. Find the Highest Product Price
8. Search for a Product ID
9. Move All Zeros to the End
10. Filter Products by Price
